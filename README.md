# Fahrradschmiede Berlin — Astro Frontend

Dieses Projekt ist das Astro-Frontend für den lokalen Baukasten und verbindet sich im SSR-Modus mit dem XAMPP/PHP-Backend.

## Voraussetzungen

- Node.js & pnpm (empfohlen) oder npm
- XAMPP (Apache & MySQL) läuft lokal

## Erste Schritte (Installation)

1. **Abhängigkeiten installieren:**

   ```bash
   pnpm install

   or

   npm install
   ```
